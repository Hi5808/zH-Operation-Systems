# Operation-Systems
Various Operating Systems

## Guides

- [Porting Mainline Linux to Any Unsupported Android Device](docs/android-linux-porting/00-overview.md) —
  vendor-agnostic, end-to-end methodology for dumping firmware, reverse
  engineering closed drivers/HALs with Ghidra, and porting a Linux-based
  OS (postmarketOS, Ubuntu Touch, Debian) to hardware with no official
  Linux support. Covers Qualcomm, MediaTek, Samsung Exynos, UNISOC,
  HiSilicon, and tablet-class Allwinner/Rockchip/Tegra devices, with a
  per-vendor reference, a fill-in device-profile template, and a
  troubleshooting chapter.
