# Provenance / how to extract from the OEM firmware
# ===========================================================================
# OEM source  : Anbernic RG405M V1.15 Unbricker (official stock firmware .pac)
# Top-level firmware blobs (wcnmodem.bin, gnssmodem.bin, l_*.bin, pm_sys.bin,
#   vbmeta*, boot/vendor_boot/dtbo/super.img, uboot.bin, sml.bin, trustos.bin,
#   fdl1-sign.bin, fdl2-sign.bin, ums512_1h10.xml) come straight out of the .pac:
#     # unpack the .pac (e.g. with pacextractor / spd_dump / imjtool)
#     pacextractor Anbernic-RG405M-V1.15.pac  out/
# Vendor-partition files (the vendor/ paths above) live in the dynamic super:
#     simg2img super.img super.raw            # if sparse; else skip
#     lpunpack super.raw .                     # -> vendor.img (+ system/product/odm)
#     fsck.erofs --extract=vendor_out vendor.img
#     # then copy the vendor/ paths out of vendor_out/
