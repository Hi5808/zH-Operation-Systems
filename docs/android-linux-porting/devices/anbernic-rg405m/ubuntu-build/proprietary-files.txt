# ===========================================================================
# Provenance / how to extract from the OEM firmware
# ===========================================================================
# OEM source : Anbernic RG405M V1.15 Unbricker -> Firmware/Firmware.pac (6.33 GB)
# Top-level firmware blobs (wcnmodem.bin, gnssmodem.bin, l_*.bin, pm_sys.bin,
#   super, boot, vbmeta*, uboot.bin, sml.bin, trustos.bin, fdl*-sign.bin,
#   ums512_1h10.xml): unpack the .pac, e.g.
#     pacextractor Firmware.pac out/         # or spd_dump / imjtool
# Vendor-partition files (the vendor/ paths above) live in the `vendor` EROFS.
# Two ways to get it out of the .pac:
#   (a) lpunpack the dynamic super, then extract the vendor EROFS:
#         simg2img super.img super.raw       # if the .pac stores super sparse
#         lpunpack super.raw .               # -> vendor.img
#         fsck.erofs --extract=vendor_out vendor.img
#   (b) if super is stored RAW and lpunpack/extraction give a truncated image
#       (as the Anbernic V1.15 .pac does), carve the vendor EROFS straight out of
#       the .pac by its superblock magic — the method used for the hashes here:
#         # scan the .pac for EROFS superblocks (magic 0xE0F5E1E2 at part_start+1024);
#         # vendor = the ~763 MB one (here at .pac offset 2477768688, size 800944128);
#         dd if=Firmware.pac of=vendor.img bs=1 skip=2477768688 count=800944128
#         fsck.erofs --extract=vendor_out vendor.img
# See ../../07-tools-reference.md §7.0 for the toolchain and the liblp/EROFS notes.
